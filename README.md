# OT-deadline

Ushbu repositoryda C dasturlash tilida yozilgan bir nechta dasturlar mavjud. Dasturlar quyidagi mavzularni qamrab oladi:
- Matritsalar bilan ishlash (ko'paytirish).
- Satrlarni so'zlarga ajratish va dinamik xotira boshqaruvi.

## Dasturlar haqida

### 1. `main.c`
**Tavsif:**
- Ushbu dastur ikki matritsani ko'paytiradi.
- Matritsalar statik massivlarda saqlanadi.
- Matritsa o'lchamlari foydalanuvchi tomonidan kiritiladi va tekshiriladi.

**Ishlatish:**
1. Dastur kompilyatsiya qilinadi:
   ```bash
   gcc main.c -o main
